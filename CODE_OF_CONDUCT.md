# Code of Conduct

## Our Commitment

We want bDoci to be a respectful, practical, and welcoming project for everyone who contributes, reports issues, reviews code, or participates in discussion.

Participants in this project are expected to act professionally and respectfully in all project spaces, including issues, pull requests, discussions, and related project interactions.

## Expected Behavior

- Be respectful in language, tone, and technical disagreement.
- Focus feedback on the code, behavior, or proposal rather than the person.
- Assume good intent, but be clear and direct when pointing out problems.
- Share constructive review comments that help move the project forward.
- Respect different experience levels and learning paths.

## Unacceptable Behavior

- Harassment, personal attacks, intimidation, or discrimination.
- Trolling, baiting, or intentionally disruptive behavior.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Sexualized language, imagery, or unwanted advances in project spaces.

## Enforcement

Project maintainer(s) may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that do not align with this Code of Conduct.

Repeated or severe violations may result in temporary or permanent removal from project spaces.

## Reporting

If you experience or witness unacceptable behavior, report it through:

- GitHub issues, if the matter is appropriate for public handling
- Direct contact with the maintainer: [@Bimbok](https://github.com/Bimbok)

All reports will be reviewed in good faith and handled as responsibly as possible.

## Scope

This Code of Conduct applies within this repository and in official project interactions related to bDoci.
