# Support

## Getting Help

If you need help with bDoci, use the appropriate channel based on the type of request.

### Use GitHub Issues For

- Reproducible bugs
- Focused feature requests
- Documentation problems
- Setup issues that can be clearly described

### Before Opening an Issue

- Check the [README.md](README.md) for setup instructions
- Read the [CONTRIBUTING.md](CONTRIBUTING.md) guidelines
- Review [SECURITY.md](SECURITY.md) first if the issue may be security-sensitive
- Search existing issues first
- Gather logs, screenshots, device details, and reproduction steps

## Security Issues

Do not report security vulnerabilities in public issues.

See [SECURITY.md](SECURITY.md) for responsible reporting guidance.

## Maintainer Contact

For project-level questions or follow-up:

- GitHub: [@Bimbok](https://github.com/Bimbok)

## Scope of Support

Support is best-effort and generally prioritizes:

- Reproducible defects
- Active regressions
- Clear setup blockers
- Security-sensitive concerns
